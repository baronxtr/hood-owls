# Hood Owls

A night hunter of the Hood. One of 1,000 pixel owls keeping watch over Robinhood Chain.

- **Supply:** 1,000
- **Chain:** Robinhood Chain (chain ID 4663)
- **Contract:** [0xbc5557a462791262601193b3dda4cad665caa2c9](https://robinhoodchain.blockscout.com/address/0xbc5557a462791262601193b3dda4cad665caa2c9)
- **OpenSea:** [hood-owls-247517409](https://opensea.io/collection/hood-owls-247517409)
- **Mint price:** free (gas only)
- **Phases:** GTD 19:00-20:00 WIB, 22 Nov 2026 (allowlist, 3 wallets) — Public from 20:00 WIB
- **Limit:** 1 per wallet per phase

## The owls

1,000 unique pixel-art night owls, drawn on a 32x32 grid and upscaled to 512x512. Seven trait dimensions: Body Color (8), Belly Pattern (4), Eye Color (6), Hat (5), Hat Color (4), Background (8 night colors), Accessory (4). Every combination is unique.

The collection was created as a test mint target for a Telegram auto-mint bot — a real on-chain drop, free to mint, built to prove the bot works end to end.

## Metadata and images

Each token's image is embedded directly in its metadata JSON as a `data:image/png;base64,...` URI — the documented on-chain media pattern, so the art needs no external image host. The metadata files themselves are served from this repo through jsDelivr:

- Token metadata: `https://cdn.jsdelivr.net/gh/baronxtr/hood-owls@main/metadata/0001.json`
- Collection metadata: `https://cdn.jsdelivr.net/gh/baronxtr/hood-owls@main/collection.json`

The on-chain token base URI is `https://cdn.jsdelivr.net/gh/baronxtr/hood-owls@main/metadata/`, so `tokenURI(1)` resolves to `metadata/0001.json`.

The original PNG files are generated by `scripts/generate.py` and are not stored in this repo; every token's image lives inside its metadata JSON.

## Reproduce the art

```bash
cd scripts
python3 generate.py
```

Same fixed seed (`20261122`), same 1,000 owls, byte for byte.
